# Temu 深度知识（通用协议版——随技能分发，本机 experiences 笔记只做增量补充）

更新：2026-10-07 · 来源：scrader 实战（搜索/采集/翻页/封锁恢复全链路，jp 站）

## 页面特性

- **虚拟列表**：视口外卡片不在 DOM，滚过即卸载；需滚动-采集-合并（harvest 内置）
- **滚动重置陷阱**：在已加载内容底部附近连续滚滚轮 → 列表整体重置回第一页。长距离移动用程序化 `scrollTo` 瞬跳（不触发），滚轮只做小步增量
- **哈希类复用**：CSS 类定位不可靠，一律「精确文本 + role=button 祖先 + 视口水平中心」启发式（scrader click 的 text 参数已内置）
- **离屏卡片 innerText 为空**（懒渲染）：文字按渲染加载，`textContent` 完整。自写采集代码勿只读 innerText（harvest ≥0.4.1 已内置回退）
- **商品卡 `target=_blank`**：点击后详情开在新标签，原页 URL 不变——进入判定要查新标签（act 层 open_item 已内置自动学习）
- 懒渲染：元素要滚到附近才进 DOM，操作前现查、不缓存引用

## locale 变体（同一站点、不同入口、不同 UI 语言！）

| 入口 | UI 语言 | 加载更多按钮 | 已售字段 |
|---|---|---|---|
| 搜索深链 / jp-zh-Hans 页 | 中文 | 「查看更多商品」 | 约半数有「已售N件」 |
| /jp/ 纯日语分类页 | 日语 | 「もっと見る」/「他の商品をもっと見る」 | **全站无已售**（正常，非缺陷） |

**按钮/字段匹配一律双语正则**：`/^(查看更多|もっと見る|他の商品をもっと見る)/`。中位价参考：日语 T 恤类 ~1,300 円。

## 封锁签名表（guard --check 自动检测）

| 信号 | 形态 | 定性 | 响应 |
|---|---|---|---|
| `bgn_no_access.html` | URL 重定向 | 硬封锁 | 停手，`--block 20` 起冷却，零请求 |
| 验证页（refer_page_name=bgn_verification） | URL/页面 | 硬封锁 | 同上 |
| "No internet connection" 页 | Temu SW 离线墙 | 软信号 | curl 对照：通=浏览器侧问题；不通=链路/代理（**先问用户是否在动代理**） |
| 列表 URL 但 0 卡片 | DOM | 疑似软拒 | 等 10s 重探；仍 0 视同硬封锁 |
| ERR_CONNECTION_RESET | 网络 | 多为链路 | curl 对照 + 问环境，勿急着定性风控 |

**恢复序列**：冷却到期 → `guard --unblock` → `guard --warmup`（首页种 cookie → 停留 → 轻浏览）→ 轻量试水 ≤40 条 → 正常采集。

## 采集参数（首选：`collect.js` 一条命令，内部自动走协议；配方本体在仓库 `recipes/temu/accumulate_human.js`，用户目录同名文件仅做本机增量）

```
harvest/accumulate 字段（MSYS 下正则避免反斜杠；双语——UI 语言随入口变，一次给全）:
  itemSelector: a[href*='-g-']     stableIdPattern: -g-([0-9]+)[.]html    cardLevels: 4
  price:        ([0-9][0-9,]*)円
  originalPrice: 原价[ ]*([0-9,]+)円 | 元[々々]の価格[ ]*([0-9,]+)円
  soldCount:    已售([0-9,.]+[万KMBkmb]?[+]?)件 | ([0-9,.]+[万]?)販売
  （日语 UI：已售="N販売"、原价="元々の価格"；纯 /jp/ 分类页两者皆无属正常）
```

- 标题清洗：零宽字符先清再剥「首选好物/从日本发货/广告」前缀与「在新标签页中打开。」后缀（recipes export 已内置）
- 图片：卡内取最大且宽 ≥120 的产品图（harvest 内置 score 过滤）
- 验收基准：40 条 → 0 缺标题/价格/图片、37+ 唯一图；200 条 5 批约 8 分钟（含拟人节奏与冷却）
- 搜索：`#searchInput` fill → 受信 Enter 或 `form.requestSubmit()`（合成 Enter 被忽略）；新实例先温启再搜索，直接深链 search_result 会被 SW 离线页兜底（像被拒，其实没有）
- 翻页：程序化 scrollTo 瞬跳 + UIA/文本定位按钮 + 前台拟人点击 + 2~6s 抖动；按钮必须在视口内才响应
- **受信输入通道可能 60s 超时**（fill/scroll 的 humanize 路径偶发）：降级路径 = 合成事件 + `form.requestSubmit()`（2026-10-07 pi 实测两次超时后全通）；频发时排查桥接 CDP 通道
- 断点续采：配方按 stableId 合并 OUT 文件，中断重跑自动续

## 单日限额（guard 默认，种子可调）

daily_cap 800 条 / 单次 ≤300 / 批间冷却 45~120s / 封锁冷却 ≥20 分钟。多日大目标拆天跑——贪量是最常见的封号原因。
